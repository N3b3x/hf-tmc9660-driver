Detailed Description

TMC9660 bootloader interface and configuration structures.

This file provides comprehensive bootloader functionality for the TMC9660 including memory operations, configuration management, OTP programming, and system initialization. The bootloader is essential for configuring the TMC9660 before transitioning to parameter mode operation.
